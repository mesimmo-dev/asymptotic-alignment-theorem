# Asymptotic Alignment Theorem

SQL exploration of convergence, deviation, and alignment across sequential observations.

## Overview

This repository models a simple sequence in which observed values progressively approach a defined target.

The dataset tracks sequential observations and compares each value against the target using deviation and alignment metrics.

## Core Concepts

- Sequential data modeling
- Convergence analysis
- Absolute deviation
- Alignment ratios
- Calculated fields
- Ordered analytical queries

## Language

SQL

## Purpose

The repository is a compact SQL exercise focused on numerical comparison, derived metrics, sequential analysis, and query-based evaluation of convergence toward a target.
